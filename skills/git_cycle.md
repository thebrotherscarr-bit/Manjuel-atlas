# Skill: The whole version-control turn
- **Action Keyword:** git_cycle
- **Description:** Runs the FULL version-control cycle in one act: reads the suites' verdict and refuses to ship on a red or stale one, shows what is about to be committed, commits with your message, pushes, and then VERIFIES the remote actually moved by comparing the local and remote heads. Use it when you want the work landed, not inspected - git_status, git_commit and git_push remain for one step at a time. It reports what the tools said and nothing else; no seat narrates a commit hash.
- **Parameters Needed:** <content>The commit message, in your own words. It is the one part of this a machine cannot supply.</content>
- **Says:** ship it | land this | commit and push | push it up | do the git cycle | full git cycle | version this
