# Skill: Git Commit
- **Action Keyword:** git_commit
- **Description:** Stages every change in the ground and commits it locally with a message. This is local versioning - it does not reach any remote. Use it to mark a point the work can be returned to. Nothing is lost by committing; git keeps what it is given.
- **Parameters Needed:** <content>One line saying WHAT CHANGED, e.g. "add intent pre-routing and stale-lock detection". Never the word git_commit -- naming the tool is not a message.</content>
