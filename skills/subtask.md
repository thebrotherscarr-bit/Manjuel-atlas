# Skill: Sub-task

- **Action Keyword:** subtask
- **Description:** Hands ONE scoped piece of work to a fresh run with its own context, and returns only its result. Use when a request has a part that is substantial on its own — a file to read and report on, a search to run and summarise — and holding all of it in this turn would crowd out the rest. The sub-task cannot see this conversation, so state it whole. At most three per turn, and a sub-task may not start another.
- **Says:** hand it off, farm it out, as a sub task, spin off a task
- **Parameters Needed:** <content>The sub-task, stated as a complete objective on its own — it cannot see this conversation or the objective above it.</content>
