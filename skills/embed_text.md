# Skill: Index One File Now
- **Action Keyword:** embed_text
- **Description:** Adds or refreshes a single workspace file in the semantic index immediately, without a full sweep. Use this right after writing a file so it becomes findable by semantic_search straight away. For a whole ground, use index_ground instead.
- **Parameters Needed:** <filepath>filename.ext</filepath>
- **Path Args:** filepath -> workspace
