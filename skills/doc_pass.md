# Skill: The Doc Pass

- **Action Keyword:** doc_pass
- **Description:** Where this estate stands today and what is on the table — the DAYBOOK's newest entry and whether it was closed, the HANDOFF's newest block, the CHANGELOG's Unreleased entries, the open lines of TASKS, the repository (branch, head, dirty, local against remote, version), and the six proofs the boot report reads. Every line is read from the record; nothing is generated. Use for "where do we stand", "what's on the table", "review the daybook and runbook", "do the doc pass", "what has landed since the tag".
- **Parameters Needed:** None
- **Says:** where do we stand, where does the estate stand, whats on the table, what is on the table, do the doc pass, run the doc pass, review the record, review the daybook, where is the repo at, what has landed since the last tag, what is open

It never writes TASKS.md. READ FIRST item 6 is explicit that a hand does not
add work to that file, and a tool that could write it would be the fastest way
there is to break that rule. It reads his list and reports it back.
