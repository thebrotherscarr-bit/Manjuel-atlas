# Skill: Skill Search

- **Action Keyword:** skill_search
- **Description:** Finds which of this chain's skills bear on a subject, and reports each one's own description in full — read from `skills/*.md`, never summarised. Use for "what can you do about X", and for any question ABOUT a tool ("what does deep research do?", "when should I use the router?"), which must be ANSWERED rather than obeyed. Nothing is executed: this reads declarations.
- **Says:** what can you do about, what skills do you have for, which tool would, is there a skill for
- **Parameters Needed:** <content>The subject, or the name of the tool being asked about.</content>
