# Skill: Read the rack
- **Action Keyword:** rack_report
- **Description:** Reports the observed state of the rack - models installed, loaded in VRAM, declared by this ground, missing, and the VRAM budget. FACTS ONLY: the numbers are collected in python and no seat is woken to read them. Ask for a judgement in the question - should I, what would you recommend, is it worth, any concerns - and the Quartermaster reads the same inventory beside it, labelled as a seat's words. Use for any question about what models are present, what is loaded, what is taking up the card, or whether there is room.
- **Parameters Needed:** <content>The question about the rack, e.g. "is there room for the coder?" for the numbers, or "should i drop a model?" to be advised as well.</content>
