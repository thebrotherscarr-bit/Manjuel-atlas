# Skill: Ask the Quartermaster
- **Action Keyword:** rack_report
- **Description:** Gathers the observed state of the rack - models installed, loaded in VRAM, declared by this ground, missing, and the VRAM budget - and has the Quartermaster read it back in plain words. Use for any question about what models are present, what is loaded, what is taking up the card, or whether there is room.
- **Parameters Needed:** <content>The question about the rack, e.g. "is there room for the coder?"</content>
