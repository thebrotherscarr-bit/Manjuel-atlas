# Skill: Propose a Memory
- **Action Keyword:** remember
- **Description:** Proposes a note to carry into later sessions - a decision, a ruling, a correction, something learned. The entry is STAGED, not remembered: it is stamped as model testimony and waits for the operator to land it. Use it when something is worth keeping beyond this run. Optionally pass a short title as filepath.
- **Parameters Needed:** <content>The note to propose</content>
