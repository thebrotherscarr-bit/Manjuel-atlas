## Skill Report

- **Action Keyword:** skill_report
- **Description:** Lists every skill the chain can actually execute, with what each one does — read from the loaded library, never generated. Use for "what skills do you have", "what are your tools", "what can you do".
- **Parameters Needed:** None

"What can you do" is a harness fact. Sitting 25 asked it twice and got a
shrug both times, because the manifest sat in memory and no seat could reach
it. A capability list must never be generated: a model reciting its tools
invents ones it does not have.
