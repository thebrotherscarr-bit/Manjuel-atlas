# Skill: Read Workspace File
- **Action Keyword:** read_file
- **Description:** Reads the raw text content of a specific file inside the workspace.
- **Parameters Needed:** <filepath>filename.ext</filepath>. A LARGE file comes back as part 1 of N; add <content>2</content> for the next window, or a heading's text to jump to that section.
- **Path Args:** filepath -> workspace
