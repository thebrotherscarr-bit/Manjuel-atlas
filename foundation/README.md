# Foundation

The estate's founding documents live here — copied in by the operator, by
hand, from outside the ground. No agent reads or writes the Archive; what
appears in this folder is what the operator chose to bring.

Drop files here and run `/index`. From then on the chain can cite them:
"what are the founding documents" becomes a search of the actual text, with
the age of each passage shown, rather than a seat's paraphrase.

Anything here is treated as REFERENCE — read, indexed, quoted, never
modified. Secret-named files are refused by the indexer whatever folder
they sit in.
